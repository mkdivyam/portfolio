How I approached it

Cleaned the order data, then built category and month aggregates in a CTE so every later step reads from one tidy base. Window functions handled month-over-month change without self-joins. Assumptions and edge cases are noted in the repo.

The key query

WITH monthly AS (
  SELECT category,
         DATE_TRUNC('month', order_date) AS month,
         SUM(profit) AS profit,
         SUM(sales)  AS sales
  FROM orders
  GROUP BY 1, 2
)
-- margin and month-over-month change, per category
SELECT category, month,
       ROUND(profit / NULLIF(sales, 0) * 100, 1) AS margin_pct,
       profit - LAG(profit) OVER (PARTITION BY category ORDER BY month) AS mom_change
FROM monthly
ORDER BY category, month;
